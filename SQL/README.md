# SQL – Database Exercises

## What it is

A collection of SQL exercises covering database design, normalization,
and query writing, created as part of a university database course.

## Contents

| File | Description |
|---|---|
| `script.sql` | contains tables, triggers and inserts |
| `ERmodel.pdf` | contains the entity relationship model as well as the relationscheme|
| `planning.pdf` | contains every attribute with its subattributes |

## How to use

Run the scripts in any SQL client:
1. Execute `script.sql` to create tables, triggers and fill tables

## What I learned

- Designing normalized schemas
- Writing joins, aggregations, and subqueries
