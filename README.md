# Uni Projects

A collection of smaller university projects that don't warrant their own repository.
Each folder contains its own README with details, setup instructions, and results.

## Projects

| Project | Description | Tech | Runnable locally |
|---|---|---|---|
| [Binary Clock](binaryclock/) | Binary clock on a custom-made PCB | KiCad, C / Embedded | no (custom hardware) |
| [Protocol](protocol/) | Full-duplex protocol on the university PCB boards | C / Embedded | no (university lab only) |
| [Stardew Valley inspired Database](SQL/) | Database design and query exercises | SQL | yes (any SQL client) |
| [Paper: Dead Internet Theory](paper/) | Mini research paper | LaTeX / Markdown | no (document) |

## Notes
These projects were created during my studies and are kept here for reference. All of them predate my use of Git so this repository contains a curated
selection of the final results rather than a full commit history.
Some target specific hardware and are not runnable on standard machines -
see each folder's README for details.
